
# 📊 ElectViz – Election Data Visualization for Media

ElectViz is an interactive **Power BI dashboard project** developed to analyze Indian election results across **2009, 2014, and 2019**. The project transforms election data into meaningful visual insights using **Power Query, DAX, data modeling, and interactive visualizations**.

## 🎯 Project Overview

The dashboard provides insights into:

* Election results and key KPIs
* Historical voting trends
* Party-wise vote and seat distribution
* Constituency-wise voter turnout
* Candidate performance
* Regional participation patterns
* Year-wise election comparison

## 📊 Dashboards

The project contains **5 interactive dashboard pages**:

1. **Election Overview** – Provides KPIs, vote share, turnout, and overall election statistics.
2. **Historical Trends** – Analyzes voting and turnout trends across different election years.
3. **Real-Time Results** – Simulates a live election results dashboard with dynamic year filtering.
4. **Voter Turnout & Demographic Insights** – Analyzes voter participation across constituencies and years.
5. **Party & Candidate Insights** – Provides party-wise and candidate-level performance analysis.

## 🧮 Key Features

* Interactive Year Slicers

* Constituency-level turnout analysis

## 🚀 How to Use

1. Install **Microsoft Power BI Desktop**.
2. Clone or download this repository.
3. Open `ElectViz.pbix` in Power BI Desktop.
4. Use the Year Slicer to select **2009, 2014, or 2019**.
5. Navigate through the 5 dashboard pages to explore the analysis.

## 📌 Project Outcome

ElectViz demonstrates how election data can be transformed into **interactive dashboards and analytical insights** using Power BI, DAX, Power Query, and data modeling.
